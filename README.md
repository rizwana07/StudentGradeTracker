# StudentGradeTracker


## Description:
This Java application helps teachers manage and track student grades. The program allows adding students, assigning grades, and generating reports.

## Features:
- Add students.
- Assign grades.
- View grades and reports.

## Technologies Used:
- Java

## How to Use:
1. Clone this repository:
   ```bash
   git clone https://github.com/rizwana07/StudentGradeTracker.git

2. Open the project in your preferred IDE (e.g., Eclipse, IntelliJ).


3. Locate and open the Main.java file.


4. Run the Main.java file to start the application.
